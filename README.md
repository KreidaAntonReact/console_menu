# console_menu

## Homework-1

Консольное меню с тремя учебными задачами на Node.js: билетная касса, доставка заказа и лестница.

## Запуск

```bash
pnpm install
pnpm start
```

Для разработки с автоперезапуском:

```bash
pnpm dev
```

После запуска появится меню:

```
Выберите задачу:
1 — билетная касса
2 — доставка заказа
3 — лестница
Ваш выбор:
```

## Пункты меню

### 1 — Билетная касса (`ticket-price.js`)

Запрашивает категорию билета и бюджет в рублях.

| Функция | Описание |
| --- | --- |
| `ticketPrice(category)` | Через `switch` возвращает цену: 1 → 300, 2 → 500, 3 → 900, иначе 0 |
| `maxTickets(budget, price)` | Циклом `while` считает, сколько билетов можно купить (без деления и округления) |
| `calculateTicketResult(category, budget)` | Считает результат и печатает чек; для неизвестной категории — `неизвестная категория` |
| `printTicketResult(rl)` | Запрашивает данные у пользователя |

### 2 — Доставка заказа (`delivery-price.js`)

Запрашивает расстояние до клиента (км) и сумму заказа (руб.).

| Функция | Описание |
| --- | --- |
| `getDeliveryPrice(distance, total)` | Считает стоимость доставки: бесплатно при заказе ≥ 3000 или расстоянии ≤ 3 км; 200 руб. при 4–10 км; дальше 200 + 25 руб. за каждый км после 10-го |
| `calculateDelivery(distance, total)` | Печатает строку вида `Расстояние 12 км, заказ 2500 руб.: доставка 250 руб.` |
| `deliveryPrice(rl)` | Запрашивает данные у пользователя |

### 3 — Лестница (`steps.js`)

Запрашивает высоту лестницы.

| Функция | Описание |
| --- | --- |
| `calculateSteps(height)` | Циклом `for` печатает номера ступеней; ступень 4 пропускается (`continue`); после 10-й печатает `Дальше лестница не построена` и выходит (`break`); в конце — `Всего построено: N` |
| `printSteps(rl)` | Запрашивает высоту у пользователя |
